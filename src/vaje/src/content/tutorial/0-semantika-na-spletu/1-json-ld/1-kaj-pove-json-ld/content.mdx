# Kaj pove JSON-LD?

**JSON-LD + schema.org**

Preglejte skrajšan posnetek zapisa s prosojnice. Pri odgovarjanju uporabite uradne opise za
<a href="https://schema.org/NewsArticle" target="_blank" rel="noopener">NewsArticle</a>,
<a href="https://schema.org/datePublished" target="_blank" rel="noopener">datePublished</a> in
<a href="https://schema.org/publisher" target="_blank" rel="noopener">publisher</a>.
